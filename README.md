# spritely-examples

The scripts and tools from my YouTube videos at [@spritelystudio](https://www.youtube.com/@spritelystudio), in one place.
Each folder goes with one video and has its own README with the steps.

| Folder | Video | What it is |
|---|---|---|
| [`train-your-own-image-model/`](train-your-own-image-model/) | How to train your own AI image model, step by step | Make training pairs from your pictures or from free 3D characters, and train a LoRA for Qwen Image Edit 2511 on RunPod or your own graphics card. |
| [`claude-tools/`](claude-tools/) | AI game dev, Claude: stop making the same mistakes | A working tool that puts an outfit on every frame of a sprite sheet, the skill file that tells Claude Code when to use it, and a rules file. |

## More tools I use

| Folder | What it is |
